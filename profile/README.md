## About FilmTrack

FilmTrack is a Persian-first movie and TV tracking product designed to help people discover titles, organize what they want to watch, track viewing progress, and maintain a personal entertainment history.

The product is developed openly through a structured GitHub lifecycle with issues, pull requests, code review, automated quality gates, releases, and production verification.

## Product

The canonical FilmTrack application lives at:

**[`FilmTrack/FilmTrack`](https://github.com/FilmTrack/FilmTrack)**

Current product capabilities include:

- Movie and TV discovery
- Personal watchlist management
- Multiple watch states
- Search and bulk-selection foundations
- Personal dashboard
- Onboarding and activation flows
- Privacy-aware user lists
- FilmTrack Plus monetization foundation
- Responsive web application
- Production deployment through Vercel

## Engineering principles

FilmTrack development follows several non-negotiable principles:

- Production-safe delivery
- Pull-request based development
- Strict linting and TypeScript validation
- Automated regression testing
- Production build verification
- Explicit privacy boundaries
- Versioned releases
- Zero-downtime infrastructure changes
